---
title: not-another-luau-lib
description: Small, focused Luau libraries for Roblox.
---

Every library lives in its own repository and is published to
[ember](https://luaupm.com), [pesde](https://pesde.dev) and [wally](https://wally.run).
Pick one from the sidebar to see its API.

## Installing

```toml title="ember.toml"
[dependencies]
Thread = { name = "not-another-luau-lib/thread", version = "^0.1.0" }
```

```toml title="pesde.toml"
[dependencies]
Thread = { name = "not_another_luau_lib/thread", version = "^0.1.0" }
```

```toml title="wally.toml"
[dependencies]
Thread = "nall/thread@^0.1.0"
```
