not-another-luau-lib is a collection of small Luau libraries for Roblox. Each one does a single
thing, has no dependency it does not need, and is fully typed.

- **One repository per library.** Every library is versioned, tested and released on its own,
  so you only pull in what you use.
- **Published everywhere.** Libraries are published to [ember](https://luaupm.com),
  [pesde](https://pesde.dev) and [wally](https://wally.run) under the same version.
- **Documented from source.** The API reference of each library is generated from its Moonwave
  comments, so it never drifts from the code.
