## Layout of a library

Every library is its own repository in the
[not-another-luau-lib](https://github.com/not-another-luau-lib) organization, with the same layout:

<Files>
  <Folder name="src" defaultOpen>
    <File name="init.luau" />
  </Folder>
  <Folder name="tests">
    <File name="init.spec.luau" />
  </Folder>
  <File name="default.project.json" />
  <File name="ember.toml" />
  <File name="pesde.toml" />
  <File name="wally.toml" />
  <File name="fumablox.toml" />
  <File name="lest.toml" />
</Files>

- `src` holds the library itself, `tests` its [lest](https://github.com/lest-luau/lest) specs.
- `ember.toml`, `pesde.toml` and `wally.toml` describe the package for each registry, and must
  keep the same version.
- `fumablox.toml` configures how the API reference is generated. A repository without it does not
  appear on this site.

## Documenting

The API reference is generated by [fumablox](https://github.com/metricrb/fumablox) from Moonwave
comments. Only what has a comment is documented:

```lua
--[=[
	@class Thread

	Runs callbacks on a recycled thread instead of creating a new one per call.
]=]
```

Run `npx @metricsrb/fumablox check` in the library to catch missing or broken docs before pushing.

## Testing

CI runs `lest` and `fumablox check` on every push and pull request. Both must pass before a change
is merged.

## Releasing

A library shows up on this site once it is published to at least one registry. After a release,
the site is rebuilt when the library's CI pushes to `main`, and at least every few hours
otherwise.
