Every library is published to wally, pesde and ember under the same name, `nall/<library>`
(for example `nall/thread`).

The API page of each library shows its latest version for every registry it is on.

## Installing

<Tabs items={['wally', 'pesde', 'ember']}>
  <Tab value="ember">

Add the library to `ember.toml`, then install:

```toml title="ember.toml"
[dependencies]
Thread = { name = "nall/thread", version = "^0.1.0" }
```

```bash
embr install
```

  </Tab>
  <Tab value="pesde">

Add the library to `pesde.toml`, then install:

```toml title="pesde.toml"
[dependencies]
Thread = { name = "nall/thread", version = "^0.1.0" }
```

```bash
pesde install
```

  </Tab>
  <Tab value="wally">

Add the library to `wally.toml`, then install:

```toml title="wally.toml"
[dependencies]
Thread = "nall/thread@^0.1.0"
```

```bash
wally install
```

  </Tab>
</Tabs>

## Requiring

Once installed, the library lives in your `Packages` folder. Require it like any other module:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Thread = require(ReplicatedStorage.Packages.Thread)
```

## Versioning

Libraries follow [semantic versioning](https://semver.org). While a library is below `1.0.0`, a
minor bump (`0.1.x` to `0.2.0`) may break its API, so depend on `^0.x.y` and read the release
notes before upgrading.
